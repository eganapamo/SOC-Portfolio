# Azure Sentinel Projects

This section contains hands-on cloud security labs built using Microsoft Azure and Microsoft Sentinel.

These projects focus on real-world detection and investigation scenarios, including brute-force attacks, suspicious login activity, and alert-based investigations.

## Projects

### 1. Brute Force Detection
Simulated multiple failed login attempts followed by a successful login and created a detection rule in Microsoft Sentinel.

### 2. Suspicious Login Detection
Identified login activity from unusual IP addresses and analyzed potential account compromise.

### 3. Alert Investigation
Created and investigated Sentinel alerts using structured SOC workflows.

## Tools Used
- Microsoft Azure
- Microsoft Sentinel
- Windows Event Logs
